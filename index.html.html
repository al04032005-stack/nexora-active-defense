Nexora “Golden Rules”

  • Verify, then trust.
  • Protect our data as you would your own.
  • When in doubt, report it out.

Reporting (Nexora)

Email: Use the “Report Suspicious Activity” button in the email client (auto-creates a SOC ticket).
Teams/Slack/SMS/Deepfake audio: Create a High-Priority ticket in the IT service portal → Security Incident category. Include screenshots, originating phone number, call description, and any other evidence.

External File Sharing (Nexora)

Approved: NexoraShare (encrypted file transfer) and specific secure Microsoft Teams integrations for pre-vetted client collaborations.
Prohibited for sensitive data: public file-sharing sites and personal email.

Data Classification (Nexora)

Public: marketing/press releases • Internal: directory/announcements • Confidential: business plans, pre-public financials, most project docs • Restricted: employee PII, customer data, source code/IP, unannounced M&A.
